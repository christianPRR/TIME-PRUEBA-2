# Timestamp Camera (versión 2)

Cámara que estampa en cada foto la **fecha y hora del teléfono**, la ubicación y más datos. Las fotos se guardan en la Galería (carpeta `Pictures/TimestampCamera`).

## Funciones

- Cámara trasera y frontal (botón **Girar**)
- Flash: No / Auto / Sí (botón **Flash**)
- Zoom con dos dedos y enfoque tocando la pantalla
- Sello con: fecha y hora, dirección escrita, coordenadas GPS, altitud, brújula, mini mapa, logo, nombre de proyecto, usuario y nota
- **Ajustes**: posición del sello (4 esquinas o ancho completo), tamaño, color, opacidad del fondo, formato de fecha, y qué datos mostrar
- **Galería** dentro de la app: toca para abrir, mantén presionado para compartir
- Ícono propio

## Notas

- La dirección y el mini mapa necesitan internet. Sin internet, la foto sale igual pero sin esos datos.
- El mini mapa usa mapas de OpenStreetMap (© OpenStreetMap contributors).
- La fecha y hora son las del reloj del teléfono.

## Cómo obtener el APK

1. Sube todo al repositorio de GitHub (conservando las carpetas).
2. Entra a **Actions**, espera la marca verde y descarga **TimestampCamera-apk** en **Artifacts**.
3. Descomprime el .zip e instala `app-debug.apk` en el celular.
